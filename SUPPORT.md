# Support

Thanks for using ibkrapi4go. Here is where to get help.

## Where to ask

| I want to... | Go to |
|--------------|-------|
| Report a bug | [GitHub Issues](https://github.com/shing1211/ibkrapi4go/issues/new?template=bug_report.yml) |
| Request a feature | [GitHub Issues](https://github.com/shing1211/ibkrapi4go/issues/new?template=feature_request.yml) |
| Ask a usage question | [GitHub Discussions](https://github.com/shing1211/ibkrapi4go/discussions) |
| Report a security issue | [SECURITY.md](./SECURITY.md) — **do not** open a public issue |

## Before you ask

Please check, in order:

1. [README.md](./README.md) and the [docs/](./docs/) set, especially
   [docs/GLOSSARY.md](./docs/GLOSSARY.md) and [docs/AUTH.md](./docs/AUTH.md).
2. Existing [issues](https://github.com/shing1211/ibkrapi4go/issues) and
   [discussions](https://github.com/shing1211/ibkrapi4go/discussions).
3. The official [Interactive Brokers API documentation](https://www.interactivebrokers.com/api/).

## What to include in a bug report

- `go version`
- ibkrapi4go version (commit SHA or tag)
- IBKR OpenAPI spec version (see [docs/SPEC.md](./docs/SPEC.md) header)
- Gateway version and whether it is a paper or live account
- A **minimal reproduction** (smallest code + exact command)
- Full error output, with secrets redacted

## Scope

This project is maintained on a best-effort basis by volunteers. There is no
commercial support or SLA. Requests that are out of scope (see
[docs/ROADMAP.md](./docs/ROADMAP.md) "Non-goals") may be closed.

## Gitee users

A mirror is maintained at <https://gitee.com/shing1211/ibkrapi4go>. Issues are
triaged on GitHub; the Gitee mirror tracks releases and tags.
