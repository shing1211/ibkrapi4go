# Archive

This directory contains historical execution logs from the v1.0.0 development sprints.
These are closed sprint artifacts — planning documents, run reports, and todo lists.
They are retained for historical reference and audit trail.

**These are not user-facing documentation.** For current documentation, see:

- [docs/](../) — architecture, design contracts, ADRs, and reference guides
- [README.md](../../README.md) — SDK landing page
- [examples/README.md](../../examples/README.md) — runnable examples

The files here are organized by date. Each run subdirectory (e.g. `runs/2026-09-17-mock-gateway/`)
contains `plan.md`, `report.md`, and optionally `todos.md` and `next-phase.md` from the
orchestrator that drove that sprint.
