PrinciplesDesign Principles

OpenAPI-first

Types are generated from the official spec; the index is regenerated, not hand-maintained.

ADR-0003

Two surfaces, explicitly

/v1/api (ssoBearer) and /gw/api/* (oauth2Bearer) are distinct and both implemented.

ADR-0001 ADR-0011

Idiomatic Go, not OpenAPI-native

Generated code is a starting point; the public API wraps it in managers.

Session is a state machine

Disconnected → Initializing → Authenticated; tickle heartbeat keeps it alive.

WebSocket is channel-based

Updates as values on channels, cancelled by context.Context.

ADR-0006

Money is never float64

Represented as string or json.Number to preserve decimal precision.

ADR-0008

Order mutations never retry

Resubmitting after timeout can create duplicates — a serious financial error.

ADR-0009

Minimal dependencies

Small transitive footprint; new runtime deps require an ADR.

ADR-0004
